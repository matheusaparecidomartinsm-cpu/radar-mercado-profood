# Radar de Mercado ProFood

Portal de inteligência de mercado (foodservice, embalagens de papel-cartão e macroeconomia) para o planejamento comercial 2027 da ProFood Embalagens / Tuicial.

- `index.html` — site estático (sem build).
- `data.json` — dados exibidos; atualizado diariamente por uma rotina automática.

Deploy: Vercel (cada push na `main` publica o site).
